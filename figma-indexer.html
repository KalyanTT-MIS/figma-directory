Figma Directory Indexer

Setup Tool

1. API Token

Generate in Figma → Settings → Personal access tokens. Grant File content & Folders read, Resources → All files.

2. Paste Figma File URLs

Right-click files in Figma → Copy link. One per line. The tool indexes all pages, frames, and generates node IDs for deep linking.

3. Export for Hosting

Once indexed, export the JSON file. Host it with the viewer on GitHub Pages. Team members search without needing Figma or tokens.

After exporting, follow the GitHub Pages setup guide below.

4. GitHub Pages Setup (Free Hosting)

Steps:

  1. Create a GitHub repo called figma-directory
  2. Clone it locally: git clone github.com/yourname/figma-directory
  3. Download the viewer.html and your exported JSON file, save them in the repo folder
  4. Push to GitHub: git add . && git commit -m "Initial" && git push
  5. Go to repo Settings → Pages → Source: main branch. Save.
  6. Your directory is live at yourname.github.io/figma-directory
  7. To update: Re-index files here, export new JSON, replace the file in your repo, push. Done.
