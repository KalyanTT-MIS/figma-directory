Figma Directory Indexer

1. API Token

Generate in Figma → Settings → Personal access tokens. Grant File content, Folders read.

2. Index New Files (Optional)

Paste Figma URLs to add new files. Leave blank to skip.

3.5 Indexed Files

Click ⟳ to refresh a file with latest text. Click ✕ to remove.

4. Export

After updating files, click Export to download the JSON.
