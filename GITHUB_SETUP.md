# Figma Directory — GitHub Pages Setup

Host your searchable Figma directory for free on GitHub. Your team can access it without needing Figma accounts or API tokens.

## Files You Need

- `figma-indexer.html` — Use this to index files (you only, with your API token)
- `figma-viewer.html` — What your team sees (rename to `index.html` for GitHub Pages)
- `figma-directory-data.json` — Exported from the indexer (generated by you, auto-updated)

---

## Step 1: Create a GitHub Repo

1. Go to [github.com/new](https://github.com/new)
2. Name it `figma-directory`
3. Make it **Public** (so GitHub Pages works)
4. Create repo

---

## Step 2: Prepare Files Locally

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/figma-directory
cd figma-directory

# Download the files from this tool and save them:
# - figma-indexer.html  (for your setup only)
# - figma-viewer.html   → rename to index.html
# - figma-directory-data.json (you'll generate this next)
```

So your folder looks like:
```
figma-directory/
├── index.html                      (this is figma-viewer.html renamed)
├── figma-indexer.html              (keep for updates)
├── figma-directory-data.json       (generated by indexer)
└── .gitignore                      (optional, add: figma-indexer.html)
```

---

## Step 3: Generate Initial Data

1. Open `figma-indexer.html` in your browser
2. Paste your Figma API token
3. Paste your file URLs
4. Hit **Index Files**
5. Hit **📥 Export as JSON**
6. Move the downloaded `figma-directory-data.json` into your repo folder

---

## Step 4: Push to GitHub

```bash
git add .
git commit -m "Initial Figma Directory"
git push origin main
```

---

## Step 5: Enable GitHub Pages

1. Go to your repo on GitHub
2. Settings → Pages
3. Under "Source," select **main** (branch)
4. Click Save
5. Wait ~1 minute
6. Your site is live at `https://YOUR_USERNAME.github.io/figma-directory`

Share this link with your team! 🎉

---

## Updating the Directory

Whenever you add new files or want to refresh:

1. Open `figma-indexer.html` in your browser (local file is fine)
2. Paste your API token
3. Paste new file URLs
4. Hit **Index Files**
5. Hit **📥 Export as JSON**
6. Replace `figma-directory-data.json` in your repo folder:
   ```bash
   # Replace the old file with the newly downloaded one
   # Then push:
   git add figma-directory-data.json
   git commit -m "Update Figma Directory"
   git push origin main
   ```
7. Refresh `https://YOUR_USERNAME.github.io/figma-directory` in 30 seconds

Your team's view updates automatically—no need to send them anything.

---

## Features

✅ Search files, pages, and screens
✅ Click frames to jump to them in Figma
✅ Filter by module/project
✅ See file staleness (last modified date)
✅ No token needed for team members
✅ Free hosting on GitHub
✅ Auto-updates when you re-index

---

## Questions?

- Make sure `figma-directory-data.json` and `index.html` are in the root of your repo
- GitHub Pages caches for ~1 minute, so changes might not appear immediately
- Team members don't need GitHub accounts—it's just a public website

Enjoy! 🎨
